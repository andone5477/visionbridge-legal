# visionbridge-legal

Public legal documents for [VisionBridge](https://github.com/andone5477/VisionBridge) — an eye-tracking assistive communication iOS app for non-verbal patients.

Live site (after GitHub Pages enabled):

- Home: https://andone5477.github.io/visionbridge-legal/
- Privacy Policy (EN): https://andone5477.github.io/visionbridge-legal/privacy-policy/

The Traditional Chinese privacy policy is bundled inside the iOS app at
Settings → 隱私 → 查閱隱私政策 and is the canonical version. This English
translation is provided for reference and Apple App Store submission.
